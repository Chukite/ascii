# ASCII Field Notes

A small public gallery of two interactive ASCII scenes by [Chukite](https://github.com/Chukite)
## Explore and download

- [Open the live gallery](https://ascii.chukite.me)
- [Download both projects](downloads/ascii-field-notes.zip)
- [Annulus project](downloads/annulus-cinematic.zip)
- [Singularity project](downloads/singularity-zoom-text.zip)

Each project archive includes its ready-to-run `dist/` folder, a project note, and the MIT License. Extract an archive and open `dist/index.html` in a modern browser. The scenes use WebGL 2, so a browser with WebGL 2 support is required.

## Run the gallery locally

From this folder, start any static file server, then open its local address. For example:

```sh
python -m http.server 8000
```

Visit `http://localhost:8000`. No build step or package installation is needed.
