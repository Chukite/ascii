# Annulus

An interactive annular eclipse above a shimmering ocean, rendered as ASCII. Zoom in to reveal eclipse facts in the field of light.

## Run

Serve the `dist/` folder with a static web server, then open its local address in a browser with WebGL 2 support. For example, run `python -m http.server 8000` from inside `dist/` and visit `http://localhost:8000`.

Drag to explore, scroll or pinch to zoom, press **Space** to pause, **R** to reset, and **S** to save a PNG.
