# Annulus

An interactive annular eclipse above a shimmering ocean, rendered as ASCII. Zoom in to reveal eclipse facts in the field of light.

## Run

Open `dist/index.html` in a modern browser with WebGL 2 support. Drag to explore, scroll or pinch to zoom, press **Space** to pause, **R** to reset, and **S** to save a PNG.
