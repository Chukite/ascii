# Singularity

An animated ASCII black hole with a glowing, gravitationally lensed accretion disk. Zoom closer to reveal facts about black holes.

## Run

Serve the `dist/` folder with a static web server, then open its local address in a browser with WebGL 2 support. For example, run `python -m http.server 8000` from inside `dist/` and visit `http://localhost:8000`.

Drag to orbit, scroll or pinch to zoom, use the arrow keys to move, press **Space** to pause, **R** to reset, and **S** to save a PNG.
