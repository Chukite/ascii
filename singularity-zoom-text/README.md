# Singularity

An animated ASCII black hole with a glowing, gravitationally lensed accretion disk. Zoom closer to reveal facts about black holes.

## Run

Open `dist/index.html` in a modern browser with WebGL 2 support. Drag to orbit, scroll or pinch to zoom, use the arrow keys to move, press **Space** to pause, **R** to reset, and **S** to save a PNG.
